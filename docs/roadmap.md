# Roadmap

## Phase 1: MVP

- Domain models with CloudKit sync
- Send a request with parameters, headers, body, and Basic or Bearer auth
- Response viewer with pretty JSON, headers and timing
- Environments and interpolation
- Postman v2.1 import, which is the migration path and the first real test
  fixture

## Phase 2: v1

- The full auth set
- Cookies
- History
- cURL import and export
- Code generation
- Keyboard-driven UX, such as ⌘↩ to send and ⌘T for a new request

## Phase 3: v1.x

- Variable extraction chains (JSONPath or regex from a response into a variable)
  instead of JavaScript scripting
- Collection runner
- WebSockets
- iOS target
